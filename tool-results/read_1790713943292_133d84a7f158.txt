     1→# Задача
     2→
     3→Создай полноценное Windows 10 desktop-приложение для управления сайтом YummyAnime голосом, предназначенное для использования с дивана без необходимости постоянно брать в руки мышь и клавиатуру.
     4→
     5→Рабочее название приложения:
     6→
     7→**Anime Voice Controller**
     8→
     9→Главная идея:
    10→
    11→Пользователь запускает приложение, перед ним появляется удобный GUI с встроенным браузером. Внутри приложения открывается YummyAnime.
    12→
    13→Пользователь может управлять сайтом голосом:
    14→
    15→* открыть аниме;
    16→* найти аниме по названию;
    17→* открыть TOP-100;
    18→* открыть каталог;
    19→* открыть онгоинги;
    20→* открыть расписание;
    21→* открыть анонсы;
    22→* открыть случайное аниме;
    23→* перейти назад/вперёд;
    24→* открыть новую вкладку;
    25→* закрыть вкладку;
    26→* переключить вкладку;
    27→* выбрать аниме;
    28→* выбрать серию;
    29→* перейти на следующую серию;
    30→* перейти на предыдущую серию;
    31→* перемотать видео;
    32→* поставить на паузу;
    33→* продолжить воспроизведение;
    34→* изменить громкость;
    35→* полноэкранный режим;
    36→* выбрать озвучку;
    37→* искать аниме голосом;
    38→* сказать номер серии и автоматически открыть её;
    39→* произносить русские команды естественным языком.
    40→
    41→Приложение должно работать максимально автономно и удобно.
    42→

    46→

    48→

    52→
    53→* Windows 11 x64.

    56→

    58→
    59→* `.exe`

    68→

    70→
    71→Предпочтительный вариант:
    72→

    78→

   104→# 3. Очень важное требование
   105→
   106→НЕ создавай систему, которая зависит исключительно от координат мыши.
   107→
   108→Плохой вариант:
   109→
   110→"нажать x=500 y=300".
   111→
   112→Хороший вариант:
   113→
   114→* DOM selectors;
   115→* JavaScript injection;
   116→* поиск HTML элементов;
   117→* keyboard events;
   118→* WebView2 APIs;
   119→* MutationObserver;
   120→* анализ URL;
   121→* анализ DOM;
   122→* HTML5 video API.
   123→
   124→Координатное управление мышью можно добавить только как fallback.
   125→
   126→Причина:
   127→
   128→Сайт может изменить размер окна, разрешение, масштаб интерфейса или расположение элементов.
   129→
   130→Приложение должно быть максимально устойчивым к изменениям сайта.

   346→
   347→Сделай голосовой слой абстрактным.
   348→
   349→Например:
   350→
   351→```csharp

   363→
   364→* Whisper;
   365→* faster-whisper;
   366→* whisper.cpp;
   367→* Windows Speech Recognition.

   369→Приоритет:
   370→
   371→**локальная обработка голоса без отправки постоянного аудио в облако.**

   373→Если для первой версии Whisper слишком сложен, реализуй рабочую Windows Speech Recognition версию, но архитектуру сделай такой, чтобы Whisper можно было подключить позже.

   580→# 15. Нечёткий поиск
   581→
   582→Название аниме может быть распознано неправильно.
   583→
   584→Например пользователь говорит:
   585→
   586→> "Стальной алхимик братство"
   587→
   588→Speech-to-text может вернуть:
   589→
   590→> "Стальной алхимик братство"
   591→
   592→или:
   593→
   594→> "Стальной алхимик братство"
   595→
   596→или ошибочный вариант.
   597→
   598→Нужно использовать fuzzy matching.
   599→
   600→Можно применять:
   601→
   602→* Levenshtein distance;
   603→* normalization;
   604→* lowercase;
   605→* удаление пунктуации;
   606→* словарь известных названий.
   607→
   608→Не требовать идеального совпадения.
   609→

   805→# 23. Важная особенность плеера
   806→
   807→На странице конкретного аниме плеер загружается через iframe.
   808→

   810→

   814→

   820→iframe
   821→    ↓
   822→video player
   823→```
   824→
   825→Если iframe относится к другому origin и прямой JavaScript-доступ невозможен из-за политики браузера, НЕ ломай приложение.
   826→

   828→
   829→* URL/navigation detection;
   830→* keyboard shortcuts;
   831→* postMessage, если доступно;
   832→* WebView2 frame APIs;
   833→* DOM взаимодействие родительской страницы;
