     1→     1→# Задача
     2→     2→
     3→     3→Создай полноценное Windows 10 desktop-приложение для управления сайтом YummyAnime голосом, предназначенное для использования с дивана без необходимости постоянно брать в руки мышь и клавиатуру.
     4→     4→
     5→     5→Рабочее название приложения:
     6→     6→
     7→     7→**Anime Voice Controller**
     8→     8→
     9→     9→Главная идея:
    10→    10→
    11→    11→Пользователь запускает приложение, перед ним появляется удобный GUI с встроенным браузером. Внутри приложения открывается YummyAnime.
    12→    12→
    13→    13→Пользователь может управлять сайтом голосом:
    14→    14→
    15→    15→* открыть аниме;
    16→    16→* найти аниме по названию;
    17→    17→* открыть TOP-100;
    18→    18→* открыть каталог;
    19→    19→* открыть онгоинги;
    20→    20→* открыть расписание;
    21→    21→* открыть анонсы;
    22→    22→* открыть случайное аниме;
    23→    23→* перейти назад/вперёд;
    24→    24→* открыть новую вкладку;
    25→    25→* закрыть вкладку;
    26→    26→* переключить вкладку;
    27→    27→* выбрать аниме;
    28→    28→* выбрать серию;
    29→    29→* перейти на следующую серию;
    30→    30→* перейти на предыдущую серию;
    31→    31→* перемотать видео;
    32→    32→* поставить на паузу;
    33→    33→* продолжить воспроизведение;
    34→    34→* изменить громкость;
    35→    35→* полноэкранный режим;
    36→    36→* выбрать озвучку;
    37→    37→* искать аниме голосом;
    38→    38→* сказать номер серии и автоматически открыть её;
    39→    39→* произносить русские команды естественным языком.
    40→    40→
    41→    41→Приложение должно работать максимально автономно и удобно.
    42→    42→

   104→   104→# 3. Очень важное требование
   105→   105→
   106→   106→НЕ создавай систему, которая зависит исключительно от координат мыши.
   107→   107→
   108→   108→Плохой вариант:
   109→   109→
   110→   110→"нажать x=500 y=300".
   111→   111→
   112→   112→Хороший вариант:
   113→   113→
   114→   114→* DOM selectors;
   115→   115→* JavaScript injection;
   116→   116→* поиск HTML элементов;
   117→   117→* keyboard events;
   118→   118→* WebView2 APIs;
   119→   119→* MutationObserver;
   120→   120→* анализ URL;
   121→   121→* анализ DOM;
   122→   122→* HTML5 video API.
   123→   123→
   124→   124→Координатное управление мышью можно добавить только как fallback.
   125→   125→
   126→   126→Причина:
   127→   127→
   128→   128→Сайт может изменить размер окна, разрешение, масштаб интерфейса или расположение элементов.
   129→   129→
   130→   130→Приложение должно быть максимально устойчивым к изменениям сайта.

   279→   279→# 7. Режим дивана
   280→   280→
   281→   281→Приложение должно иметь специальный режим:
   282→   282→
   283→   283→**Couch Mode**
   284→   284→
   285→   285→В нём:
   286→   286→
   287→   287→* увеличиваются элементы UI;
   288→   288→* кнопки становятся крупнее;
   289→   289→* текст увеличивается;
   290→   290→* интерфейс становится проще;
   291→   291→* минимум мелких элементов;
   292→   292→* основные кнопки находятся снизу;
   293→   293→* голосовое управление становится главным способом управления.
   294→   294→
   295→   295→Например:
   296→   296→
   297→   297→```text
   298→   298→┌─────────────────────────────────────┐
   299→   299→│                                     │
   300→   300→│       ANIME VOICE CONTROLLER        │
   301→   301→│                                     │
   302→   302→│         ▶ Воспроизведение           │
   303→   303→│                                     │
   304→   304→│      ⏮      ⏸      ⏭               │
   305→   305→│                                     │
   306→   306→│  🎤 "Слушаю..."                     │
   307→   307→│                                     │
   308→   308→└─────────────────────────────────────┘
   309→   309→```

   345→   345→# 9. Голосовой движок
   346→   346→
   347→   347→Сделай голосовой слой абстрактным.
   348→   348→
   349→   349→Например:
   350→   350→
   351→   351→```csharp
   352→   352→interface ISpeechRecognitionService
   353→   353→{
   354→   354→    Task StartAsync();
   355→   355→    Task StopAsync();
   356→   356→    event Action<string> SpeechRecognized;
   357→   357→}
   358→   358→```
   359→   359→
   360→   360→Основной движок желательно сделать через локальное распознавание речи.
   361→   361→
   362→   362→Рассмотри:
   363→   363→
   364→   364→* Whisper;
   365→   365→* faster-whisper;
   366→   366→* whisper.cpp;
   367→   367→* Windows Speech Recognition.
   368→   368→
   369→   369→Приоритет:
   370→   370→
   371→   371→**локальная обработка голоса без отправки постоянного аудио в облако.**
   372→   372→
   373→   373→Если для первой версии Whisper слишком сложен, реализуй рабочую Windows Speech Recognition версию, но архитектуру сделай такой, чтобы Whisper можно было подключить позже.

   599→   599→
   600→   600→Можно применять:
   601→   601→

   603→   603→* normalization;

   805→   805→# 23. Важная особенность плеера
   806→   806→
   807→   807→На странице конкретного аниме плеер загружается через iframe.
   808→   808→
   809→   809→Поэтому система должна учитывать iframe.
   810→   810→
   811→   811→На исследуемой странице YummyAnime плеер находится через iframe, а сайт отдельно отображает доступные варианты озвучки.
   812→   812→
   813→   813→Архитектура должна предусматривать:
   814→   814→
   815→   815→```text
   816→   816→WebView2
   817→   817→    ↓
   818→   818→YummyAnime page
   819→   819→    ↓
   820→   820→iframe
   821→   821→    ↓
   822→   822→video player
   823→   823→```
   824→   824→
   825→   825→Если iframe относится к другому origin и прямой JavaScript-доступ невозможен из-за политики браузера, НЕ ломай приложение.
   826→   826→
   827→   827→В таком случае использовать:
   828→   828→
   829→   829→* URL/navigation detection;
   830→   830→* keyboard shortcuts;
   831→   831→* postMessage, если доступно;
   832→   832→* WebView2 frame APIs;
   833→   833→* DOM взаимодействие родительской страницы;
   834→   834→* доступные элементы управления;
   835→   835→* fallback keyboard control.
