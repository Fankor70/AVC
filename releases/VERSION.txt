AVC-Anime — манифест последней собранной версии
================================================

Файл:        AVC-Anime-Portable-1.1.0.exe
Версия:      1.1.0 (post-release fixes: голос, команды, запуск, модели, UI, тема)
Размер:      384993748 байт (~385 МБ)
SHA-256:     ff9447a409c0bc8eaae6c9371713b93701a761e635656d2a134e867d83e00f1e
Собран:      2026-10-03 (локальная сборка, Next.js 16 + Electron 33.2.0)
Коммит:      см. GitHub Release v1.1.0
Платформа:   Windows x64 (portable, установка не требуется)

Что нового в 1.1.0:
- Голос в EXE: локальный офлайн-движок по умолчанию («Авто» = T-One STT);
  честные статусы вместо вечного «Слушаю»; детектор мёртвого микрофона;
  перезапуск голосового сервиса в Диагностике
- Команды: «Наруто» = поиск (не «неизвестная команда»); «Наруто 1 серия»
  открывает ИМЕННО Наруто (явный тайтл сильнее текущего аниме); «Блич 20 серия»,
  «Наруто Шиппуден 10 серия», серии до 4 цифр
- Запуск: телеметрия стартовых меток (userData/logs/startup-report.json);
  STT готов сразу, TTS/LLM догружаются фоном/по требованию
- AI-модели: Настройки → AI — выбор каталога с безопасной миграцией
  (копирование → сверка → рестарт; старая папка сохраняется)
- Интерфейс: адаптивная панель команд (ввод не сжимается и не перекрывается)
- Тема: Navy Blue (токенизированная, cyan-акценты)

Состав сборки (проверен при упаковке):
- Next.js UI: standalone-сервер (resources/next-app)
- Prisma/SQLite: query engine Windows
- Постоянная сессия YummyAnime (partition persist:yummyanime)
- Локальный AI: sherpa-onnx-win-x64 + node-llama-cpp 3.22.1 win-x64 + Node 22.11.0
- Модели STT/TTS/LLM скачиваются при первом включении AI (папку можно выбрать)
