# INSTALLER_AI_SETUP — мастер первого запуска AI

Дата: 2026-10-03 · Спецификация §50–§60, §107–§110, §127–§129

## Пользовательский сценарий

```
Скачать AVC-Anime.exe → Запустить → UI открывается сразу (модели грузятся фоном, §49)
  → модели не установлены? → «AVC-Anime AI Setup»:
        Ваш ПК: CPU / RAM / Диск / GPU  (§50–§51)
        Список моделей с РЕАЛЬНЫМИ размерами из манифеста:
          [x] STT · T-One Russian Streaming CTC · 122.5 МБ (требуется)
          [x] VAD · Silero VAD · 0.6 МБ (требуется)
          [x] TTS · Ирина (женский) · 64 МБ (опционально)
          [x] LLM · Qwen3-0.6B Q4_K_M · 462 МБ (опционально)
        Всего к загрузке: XXX МБ · Свободно: XXX ГБ
        Кнопки: «Установить» · «Настроить» (выбор компонентов) · «Пропустить AI» (§52, §59)
  → Установить → прогресс по фазам (§56):
        загрузка % → проверка SHA-256 → распаковка → готово
  → инициализация сервисов → AI READY
```

## Что под капотом

- Мастер: `src/components/avc/ai-setup-dialog.tsx`; авто-открытие только в EXE,
  когда есть неустановленные модели и пользователь ранее не нажимал «Пропустить»
  (localStorage `avc-ai-setup-dismissed`); повторный запуск — Настройки → AI →
  «Мастер установки».
- Загрузки: `ai/model-manager.cjs` — temp .part → HTTP Range resume → проверка
  размера → SHA-256 → атомарный rename → распаковка tar.bz2 → проверка структуры →
  маркер `.avc-installed.json`. Частичная загрузка НИКОГДА не помечается
  установленной (§56); после перезапуска install() продолжает с Range-позиции (§57, §128).
- Ошибки (§58): конкретные — HTTP 404/403/5xx, TLS, timeout, SIZE, CHECKSUM,
  DISK_FULL, EXTRACT — с текстом на русском; кнопки повтора — повторный «Установить».
- Независимость компонентов (§129): можно установить только STT+VAD (голосовой ввод
  работает), только +TTS (плюс ответы голосом), без LLM (детерминированные команды
  работают полностью).

## Хранилище (§54)

- packaged: `%LOCALAPPDATA%/AVC-Anime/ai-models/` (userData)
  - `stt/t-one-russian/` — model.onnx, tokens.txt, маркер
  - `vad/silero-vad/` — silero_vad.onnx, маркер
  - `tts/irina|ruslan|dmitri/` — *.onnx, tokens.txt, espeak-ng-data/, маркер
  - `llm/qwen3-0.6b/` — *.gguf, маркер
  - `tts-cache/` — WAV-кэш фраз (§24)
- dev: `electron-app/models/` (та же структура)

## Манифест (§55, §115)

`electron-app/ai/models-manifest.json` — единственное место URL. Все размеры и
SHA-256 — сняты с РЕАЛЬНЫХ загрузок (инструмент `tools/ai-sha-update.cjs`), ничего
не выдумано. Проверка перед сборкой — `scripts/validate-ai-assets.mjs` (§61–§66,
§116–§118): HEAD+докачка 1 МБ; `--full` — полная загрузка + SHA. FAIL требуемого
ассета останавливает сборку (§117) — шаг встроен в CI-workflow ДО electron-builder.
