# Skip Segments — пропуск опенинга/эндинга/рекапы

Статус: реализовано ядро + Aniskip + пользовательские отметки (релиз 1.0.12+).
Голосовые команды: «пропусти опенинг/эндинг/рекап», «вернись / отмени пропуск»,
«включи/выключи автопропуск», «запомни начало/конец опенинга».

## Отклонение от исходной спецификации (честно)

PlayerAgent ВНУТРИ кросс-доменного iframe плеера (kodik/aksor) невозможен:
хост-страница и Electron не могут инъектировать скрипт в чужой iframe
(webview в приложении нет, `setWindowOpenHandler` denies popups).
**Но fullscreen в приложении СВОЙ** — контейнер `fixed inset-0 z-50` поверх
собственного UI, а не нативный fullscreen iframe. Поэтому кнопка пропуска
живёт в панели приложения (оверлей в правом нижнем углу видео) и видна/работает
в fullscreen — пользовательский результат тот же («кнопка с дивана»).

## Архитектура (три заменяемых слоя)

```
1) Источники таймкодов (провайдеры, приоритет по каскаду)
   P3 user marks  — «запомни начало/конец опенинга» (Prisma SkipMark, /api/skip-marks)
   P1 site        — тайминги сайта: VideoSkips {opening,ending:{time,length}}
                    уже приходят в /api/site/anime → video.skips
   P2 aniskip     — GET api.aniskip.com/v2/skip-times/{malId}/{episode}
                    (MAL ID из remote_ids сайта; открытый API; UA приложения;
                    ≤1 req/с; Retry-After; кэш позитив 24 ч / негатив 6 ч)
   fallback       — ручные слайдеры OP/ED у плеера (существующая фича)

2) Ядро (src/lib/avc/skip/)
   core.ts     — SkipSegment, санити-валидация (длины 20–150/20–200/10–240 с,
                 позиции op<60% / ed>50% длительности), слияние (источник с
                 высшим приоритетом; совпадение границ ±2 с = +0.15 confidence)
   aniskip.ts  — клиент Aniskip: тайм-аут 4 с, типы op/ed/mixed-op/mixed-ed/recap,
                 episodeLength обязателен при известной длительности; расхождение
                 длительности >5 с → confidence 0.4 (автопропуск запрещён)
   resolver.ts — каскад + отмена по requestId (смена серии/озвучки отбрасывает
                 устаревшие ответы и таймеры)

3) Потребители
   player.tsx   — кнопка «Пропустить опенинг (N с)» (видна при start ≤ t < end−3),
                  автопропуск (mode=auto, confidence ≥ порога, задержка 3 с,
                  one-shot на серию по сегменту), защита коротких видео
   executor.ts  — голосовые интенты SkipSegment/UndoSkip/SetAutoSkip/MarkSegment;
                  seek верифицируется чтением currentTime (±1.5 с, одна ретрай),
                  честный ответ при неудаче; undo возвращает к началу сегмента
```

## Поток данных

```
playEpisode → playback{malId, episode, dub, duration, currentSkips}
Player: useEffect [url, duration, marksVersion, settings]
  → /api/skip-marks (user marks) → resolveSkipSegments()
  → { segments } → store.skipSegments
таймлайн (time_update) → кнопка / handleAutoSkip / голос «пропусти опенинг»
skip → player_seek(end) → verify(currentTime) → toast → lastSkippedSegment
«вернись» → player_seek(start)
```

## MAL ID

Сайт отдаёт `remote_ids` в `/api/anime/{id}` (поле не документировано — парсинг
защитный: `myanimelist_id` или `mal`, число либо числовая строка). Значение
протягивается в `AnimeDetails.malId` → `PlaybackContext.malId` → Aniskip.
Нет MAL ID → Aniskip пропускается, работают сайт/отметки/fallback.

## Безопасность и вежливость

- Не извлекаем видеопотоки и не ходим в приватные API плееров — только
  метаданные, которые сайт/Aniskip отдают обычному пользователю.
- Aniskip: свой User-Agent `AVC-Anime/1.0`, минимум 1.1 с между запросами,
  кэш в памяти сессии, 404 = штатное «данных нет», никаких префетчей каталога.
- Реклама: сегменты применяются только к сообщениям нашего iframe
  (`e.source === iframe.contentWindow`); подозрительно короткая длительность
  отсекается санити-валидацией.

## Настройки (Настройки → Пропуск опенинга/эндинга)

- Режим: «Выкл» / «Показывать кнопку» (по умолчанию) / «Автопропуск»
- Типы: опенинги / эндинги / рекапы (вкл/вкл/выкл по умолчанию)
- Источники: тайминги сайта, Aniskip (вкл по умолчанию)
- Порог уверенности автопропуска (50%), секунды fallback (85), очистка кэша
  Aniskip и «Мои отметки»

## Кэш

Позитив Aniskip — 24 ч, негатив — 6 ч (в памяти сессии приложения; переживать
перезапуск смысла немного, запрос лёгкий и вежливый). Пользовательские отметки —
постоянные (Prisma `SkipMark`, уникальность по аккаунт+аниме+озвучка+тип,
частичные отметки мержатся: вторая граница не затирает первую).

## Как добавить новый источник таймкодов

1. Провайдер: функция `(query: SkipQuery) => SkipSegment[] | Promise<SkipSegment[]>`
   в `src/lib/avc/skip/` (или отдельном файле) с кэшем/вежливостью своего API.
2. Подключить в `resolveSkipSegments` с приоритетом через `source` сегмента.
3. Валидация/слияние применятся автоматически (core.validateSegment/mergeSegments).
