# 🎤 Anime Voice Controller

Голосовое управление аниме-сайтом **YummyAnime** с дивана — без мыши и клавиатуры.

Веб-реализация настольного приложения (WPF + WebView2) на стеке **Next.js 16 + TypeScript**,
с точным сохранением слоистой архитектуры мастер-промпта:

```
🎤 Голос
   │
   ▼
Speech Recognition        (ASR: /api/voice/asr, z-ai-web-dev-sdk, backend-only)
   │
   ▼
Command Parser            (ЛОКАЛЬНЫЙ, детерминированный: src/lib/voice/parser.ts;
   │                       LLM-fallback: /api/voice/interpret — только при низком confidence)
   ▼
Command Executor          (src/lib/avc/executor.ts — очередь команд, контекст, обратная связь)
   │
   ┌──────┴─────────────┐
   ▼                    ▼
Browser/WebView2      Player Control
(вкладки/навигация)   (серии, плеер, озвучки, громкость, фулскрин)
   │                    │
   └────────┬───────────┘
            ▼
   YummyAnime Adapter     (src/lib/sites/yummy/adapter.ts — JSON API + HTML-секции)
```

**Ключевой принцип (мастер-промпт #3):** ни одной координаты мыши. Всё построено на
ссылках, полях, JSON API и структуре страниц. Добавить второй аниме-сайт = написать
новый класс с интерфейсом `IAnimeSiteAdapter` — остальное приложение не меняется.

## Что умеет

- **Поиск голосом / текстом:** «найди Берсерк», «открой Наруто». Несколько совпадений →
  диалог «Скажите номер», выбор: «два» / «первый».
- **Управление сериями:** «включи пятую серию», «двадцать первая», «следующая серия»,
  «предыдущая», «покажи серии». Озвучка **сохраняется** между сериями (#51).
- **Озвучки:** «озвучка AniDUB», «выбери сербин» — нечёткий поиск по фактическим
  озвучкам тайтла (их может быть 20+, включая субтитры).
- **Плеер:** «пауза», «продолжить», «вперед на десять секунд», «назад на тридцать секунд»,
  «громче», «тише», «громкость 50», «полный экран».
- **Навигация по сайту:** «открой каталог / топ сто / онгоинги / анонсы / расписание /
  случайное аниме», «на главную», «обнови».
- **Вкладки:** «новая вкладка», «закрой вкладку», «следующая/предыдущая вкладка»,
  «открой топ сто в новой вкладке». Сессия вкладок **сохраняется и восстанавливается** (#30).
- **Контекст (#107):** «двадцать» при открытом аниме = серия 20; «назад» во время видео =
  предыдущая серия, на обычной странице = история назад.
- **Комбинированные команды (#70):** «открой наруто и включи третью серию» — выполняются
  последовательно через очередь.
- **Естественный язык (#110):** «поставь мне следующую серию того аниме, которое я сейчас
  смотрю» — локальный парсер даёт низкий confidence → подключается LLM-интерпретатор.
- **Push-to-talk:** удержание 🎤 или `Ctrl + Space`. **Always-listening:** автоостановка по
  тишине, опциональный wake word («аниме, следующая серия»).
- **Couch Mode:** крупный интерфейс, минимум второстепенных элементов.
- **Голосовые ответы (TTS, отключаемые)** и **история команд** (только текст, без аудио).
- **Debug-панель (#105):** RAW → NORMALIZED → COMMAND → PARAMS → CONFIDENCE → RESULT для
  каждой команды + **диагностика YummyAnime** одной кнопкой (#86).

## Реальные данные YummyAnime

Адаптер работает через официальный JSON API сайта (без DOM-инъекций и координат):

| Ресурс | Эндпоинт |
|---|---|
| Поиск | `GET /api/search?q=` |
| Детали аниме (озвучки, «12 из 26») | `GET /api/anime/{id}` и `GET /api/anime/{alias}` |
| Матрица серий × озвучек + iframe плеера | `GET /api/anime/{id}/videos` |
| Каталог / онгоинги / анонсы / расписание / ТОП-100 | HTML `/catalog`, `/catalog/ongoing`, `/catalog/announcement`, `/catalog/schedule`, `/catalog/top` |
| Случайное аниме | `/catalog/random` (302-редирект) |

Все селекторы собраны в одном объекте `SELECTORS` внутри адаптера (#53). Секции кэшируются
в памяти (TTL 5 мин, #88). Если сайт недоступен из окружения — включается демо-датасет
(бейдж «Демо-данные»), приложение остаётся полностью работоспособным (#103).

## Запуск

```bash
bun install
bun run db:push     # Prisma + SQLite (настройки, история, сессия)
bun run dev         # http://localhost:3000
```

Микрофон: браузер запросит разрешение при первом push-to-talk. Для локальной сети
нужен HTTPS (кроме localhost), иначе `getUserMedia` недоступен — тогда используйте
тестовый ввод команд (поле внизу окна) — функциональность идентична.

## Настройки (#48)

- **Общие:** режим микрофона, wake word, Couch Mode
- **Голос:** порог уверенности (0.3–0.9), голосовые ответы (TTS)
- **Воспроизведение:** шаг перемотки (5/10/30/60), шаг громкости, громкость по умолчанию, автопереход к следующей серии
- **Приватность:** сохранять историю, LLM-fallback вкл/выкл

Всё хранится в SQLite (Prisma), применяется мгновенно.

## Известные ограничения (честно)

1. **Голосовые движки (#9):** основным движком распознавания является **Web Speech API
   браузера** (`ru-RU`, отлично поддерживает русскую речь в Chrome/Edge/Яндекс — веб-аналог
   локального Windows Speech Recognition из WPF-версии). Серверный ASR (z-ai SDK) остаётся
   fallback'ом для браузеров без Web Speech API (Firefox) — у провайдера этого ASR слабая
   поддержка русского (проверено: «пауза» → «BA, EABA»), поэтому он включается только когда
   браузерный недоступен. Whisper можно подключить позже третьим движком за интерфейсом.
2. **Плеер** воспроизводит видео через iframe официального плеера сайта
   (`player.aksor.tv` — X-Frame-Options отсутствует, встраивается). Команды пауза/перемотка
   управляют состоянием приложения (мини-плеер, таймлайн). Прямое управление
   `<video>` внутри кросс-доменного iframe запрещено браузерной политикой — в WPF-версии
   это делает WebView2 + JS bridge (#23); здесь честный fallback: iframe + наши контролы.
3. **Rate limit** серверного ASR/TTS провайдера — при всплеске появится «Сервис перегружен,
   попробуйте ещё раз» (в маршруте есть авто-retry). На браузерный движок не влияет.
4. **Always-listening** — автоостановка по тишине/концу фразы (не потоковый стриминг).
5. Парсер локальный и детерминированный (#109): LLM включается только для низкого
   confidence — сложные фразы вне словаря команд могут не распознаться.

## Добавить второй аниме-сайт

1. Создайте `src/lib/sites/название/adapter.ts`, реализуйте `IAnimeSiteAdapter`
   (search / getAnime / getSection / getRandom / getVideos / runDiagnostics).
2. В `src/lib/sites/index.ts` верните адаптер по `baseUrl` из настроек.
3. Секции задаются картой путей — команды и GUI менять не нужно.
