## Executive Summary

Что было сломано и что исправлено:

1. **Обновление скачивало релиз даже без обновления.** Root cause: методы
   `checkUpdate/installUpdate` жили в preload внутри `ai.*`, UI вызывал их на
   верхнем уровне моста → `bridge.checkUpdate === undefined` → кнопка всегда
   уходила в web-ветку (безусловное скачивание EXE). Fix: методы на верхнем
   уровне моста; полный обновлятор: сверка версий ДВАЖДЫ в main, SHA-256 до
   установки, двухфазная подмена EXE без убийства собственного дерева,
   верификация версии после перезапуска, полный UI-конвейер (UpdateDialog).
2. **Библиотека/Смотрю/В планах/оценки не показывались в EXE.** Root cause:
   `yummyLibrary()` читал web-cookie-сессию (файла в EXE нет) → вечное
   «войдите». Fix: `getLibrary()` читает реальные списки ВНУТРИ постоянной
   сессии main-процесса (эндпоинт подтверждён живой сессией), кеш с
   инвалидацией по действиям; UI без изменений (bridge-first).
3. **Установщик обновления мог убить сам себя** (`taskkill /T` по mainPid из
   его же потомка). Fix: штатный выход приложения + wait-exit + move/fallback.
4. Проверено без изменений: фикс HTTP 500 Истории (schema-sync при старте),
   голос (GigaAM v3 по умолчанию, финал ~0.5 с, retry/ resume установки),
   регресс команд (явный тайтл сильнее контекста), постоянство сессии сайта.
